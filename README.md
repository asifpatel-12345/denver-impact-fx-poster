# 🔥 Denver Imperial Hamilton – Impact FX Poster

A cinematic, animated product poster for **Denver Imperial Hamilton Deodorant Body Spray**, built with pure **HTML, CSS and JavaScript** (no frameworks).

## ✨ Features
- Gold & black fire theme with glowing rings and floating rocks
- Canvas-based flying embers/sparks animation
- Mouse-tilt 3D effect on the spray can
- Fully responsive poster (scales to any screen)
- Respects `prefers-reduced-motion`

## 📁 Structure
```
denver-impact-fx/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Run locally
Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

## 🛠️ Tech
HTML5 · CSS3 · Vanilla JavaScript (Canvas API)
